# Guitar Chords & Scales Trainer

Daily practice app for acoustic guitar (steel or nylon) that listens through the microphone: live tuner, chord check, graded scale play-along with wait-for-me mode, rhythm-switch timing, auto-counted one-minute changes, notes and CAGED chord shapes across the whole neck, note finder, ear training and analogy-led lessons.

Open it at **https://subhra-neel.github.io/Guitar-Scales/** on phone or tablet, allow the microphone, add it to the home screen, then run Settings → Calibrate timing once per device.

Everything lives in `index.html`; there is no build step.
